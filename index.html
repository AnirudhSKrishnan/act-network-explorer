ACT Electricity Network Explorer

Maps the ACT's electricity network from public OpenStreetMap data using open-source GIS tools, checks it for connectivity and data-quality problems, estimates rough nearest-substation areas, and runs a toy load flow on one 11 kV path.

  • Public OpenStreetMap data; not official network operator data; OSM power data is incomplete.
  • Service areas are rough geometric estimates, not feeder boundaries.
  • The feeder is a toy model with assumed loads and cable type.

What it does

  • Fetches OpenStreetMap power data for the ACT.
  • Cleans it and classifies lines by voltage.
  • Builds a network graph, snapping nearby line ends together.
  • Runs data-quality checks for dangling ends, floating sections, conflicting and missing voltage tags, and duplicates.
  • Estimates rough nearest-substation areas.
  • Runs a toy pandapower load flow on one 11 kV path.

Built with: Python, GeoPandas, shapely, networkx, folium, pandapower.
